GeoQuiz Application
Overview
GeoQuiz is an engaging and interactive web-based quiz designed to test users' knowledge of geography. It features a clean, responsive design enhanced with Bootstrap for a seamless user experience across different devices. The quiz fetches random geography questions from The Trivia API, presenting them to users in a multiple-choice format. The application tracks and displays the user's score in real-time, making learning fun and informative.

Features
Dynamic Questions: Fetches ten random geography questions from The Trivia API.

Real-time Scoring: Displays correct and incorrect answers as the user progresses through the quiz.

Responsive Design: Utilizes Bootstrap for a clean and responsive layout.

User-Friendly Interface: Simple and intuitive design for an engaging user experience.

Automatic Question Advancement: Smooth transitions between questions with a brief delay.

How to Use
Start the Quiz: Click the "Start" button to begin the quiz.

Answer Questions: You will be presented with multiple-choice questions. Select your answer by clicking on the corresponding button.

Live Scoring: Your correct and incorrect answers will be tracked and displayed in real-time.

Complete the Quiz: After answering all questions, your final score will be shown.

Restart the Quiz: If you wish to play again, click the "Restart" button to begin a new session.
